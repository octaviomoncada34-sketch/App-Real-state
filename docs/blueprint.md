# **App Name**: ArrendApp

## Core Features:

- Property Listing Display: Display property listings fetched from the .NET backend, including images, prices, and descriptions.
- Filtering and Sorting: Allow users to filter properties based on criteria such as price, address, and number of rooms.
- Property Details View: Provide a detailed view for each property, including all available information and a contact form.
- AI-Powered Property Suggestion: Suggest additional parameters to add to the existing filters for each property, to make its profile stand out. LLM is used as a tool here.
- Interactive Map Integration: Integrate a map to display the location of each property.
- Contact Form: Implement a contact form for users to inquire about specific properties.

## Style Guidelines:

- Primary color: Light cyan (#A0E7E5) to evoke a sense of calm and trustworthiness.
- Background color: Very light cyan (#E8F8F7), near-white.
- Accent color: Coral (#FF8A5B) to draw attention to calls to action.
- Body and headline font: 'PT Sans', a humanist sans-serif for a modern, clean, and slightly warm aesthetic.
- Use simple, geometric icons for categories and filters, aligning with the modern sans-serif typography.
- Implement a clean, grid-based layout with ample whitespace for a modern and spacious feel.
- Subtle transitions and animations on UI elements (e.g., property cards) to provide a smooth and engaging user experience.
